📚 Sobre o projeto

🔐 Criptografia

A criptografia transforma uma mensagem em um formato protegido para impedir que outras pessoas entendam seu conteúdo.

#️⃣ Hash

O Hash transforma uma informação em uma sequência de caracteres. Este projeto utiliza o algoritmo SHA-256.

🛡️ Proteção de informações

A criptografia e o hash são utilizados para ajudar na proteção de dados e na segurança da informação.
